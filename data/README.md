# Dados iniciais versionados

Estes arquivos são dados **iniciais** publicados junto com o site:

- `recados.json`: recados públicos;
- `favoritos.json`: favoritos de exemplo/compartilhados;
- `usuarios.json`: mantenha vazio. **Nunca** publique senhas, e-mails privados ou informações pessoais no Git.

## Importante

O GitHub Pages é um site estático. O JavaScript no celular pode ler estes JSONs, porém não tem permissão para alterá-los nem fazer `git commit`/`git push`.

Para publicar uma alteração feita manualmente, edite o JSON no GitHub, crie um commit e aguarde o GitHub Pages atualizar. Os dados criados pelo visitante continuam sendo salvos no navegador quando não houver um backend.
